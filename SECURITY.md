# Security policy

## Reporting a concern

Use [GitHub private vulnerability reporting](https://github.com/electricsheephq/von-neumann-probe/security/advisories/new)
for sensitive security concerns, unintended data disclosure, or unsafe executable
content linked from this project. Provide the affected document or commit, the
impact, and a minimal sanitized description. Do not post secrets or exploit details
in a public issue. No response-time guarantee is made.

## Threat notes

This is a research and documentation repository, not an operational control system
or a safety approval. Treat linked code, simulations, models, and proposed designs
as untrusted third-party material. Evaluate any implementation in an isolated,
authorized environment; research discussion does not authorize hardware deployment
or unrestricted autonomous operation.

## Data handling

Keep personal data, credentials, private designs, and sensitive operational details
out of public issues and pull requests. Use synthetic examples, redact identifying
details, and share only the minimum needed to explain a concern. Revoke or rotate
exposed credentials through their provider rather than uploading live values.

Report vulnerabilities in third-party projects through their own security channels.
